# Upscaler 4K

Windows-programma dat oude video's en foto's met AI (Real-ESRGAN) naar 4K opschaalt op een NVIDIA-kaart.

**Download:** [Upscaler4K-windows.zip](https://github.com/Obscuritatis/Upscaler/releases/latest/download/Upscaler4K-windows.zip). Pak de zip uit en dubbelklik op `Upscaler4K.exe`.

Uitleg over installeren, instellingen en extra's staat in [LEESMIJ.md](LEESMIJ.md).

De .exe wordt automatisch gebouwd bij elke wijziging (zie het tabblad *Actions*).
